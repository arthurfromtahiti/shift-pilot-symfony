# shift-pilot-symfony

Pilote de test SHIFT/Paperclip — suivi de livraisons inter-îles, sur Symfony 5.4.

## Stack

Symfony 5.4 (framework-bundle, http-kernel, routing, yaml), PHP >= 8.1, Composer.
Tests : `composer test` (PHPUnit via symfony/phpunit-bridge).

## Déploiement

Géré par Git → staging, comme le reste de la plateforme de livraison.
